# WirelessCable 使用手册

> 对应版本 **2.10.2**（2026-11-19）。覆盖电脑端（Windows）与手机端（Android）已交付的能力。  
> **给最终用户的那份在 [`使用指南.md`](使用指南.md)**——没有端口、心跳、授权模型这些内容。  
> 尚未支持：iOS、跨网段（不在同一局域网）、手机作为服务端被电脑主动连接。

---

## 1. 它是做什么的

一根"无线数据线"：**手机和电脑连同一个局域网（同一个路由器下），就能互传文件、浏览对方目录、把文件推到对方设备上**。  
有线接、Wi-Fi 接、2.4G 与 5G 都不影响——只要路由器没开「AP 隔离」、两台不在访客网络里。  
不用插线、不用装驱动、不走云盘中转，数据只在你自己的局域网里。

角色是固定的：

| 角色  | 谁  | 做什么                       |
| --- | -- | ------------------------- |
| 服务端 | 电脑 | 监听 47110 起的端口、存配对与授权、下发作业 |
| 客户端 | 手机 | 主动连电脑；**手机不监听任何端口**       |

所以"连不上"时先看电脑端是否在运行，而不是手机。

## 2. 安装

### 2.1 电脑端

系统要求：Windows 10 2004（build 19041）及以上，x64。

| 形态          | 怎么用                            | 数据放在哪                                    |
| ----------- | ------------------------------ | ---------------------------------------- |
| **便携版**（推荐） | 解压整个文件夹，双击 `WirelessCable.exe` | exe 同目录的 `Data\`、`Logs\`、`TransferTemp\` |
| 单文件 exe     | 直接双击                           | `%LOCALAPPDATA%\WirelessCable\`          |

- 首次启动会弹「放行本机端口」→ 点「继续」，随后是管理员权限（UAC）确认；它会自动加两条规则（HTTPS 端口 + mDNS 5353），不用手动设防火墙。
- 端口默认 `47110`；被占用会 1 个 1 个往后试，最多 20 次。实际端口在首页能看到。
- 便携版第一次运行会从 `%LOCALAPPDATA%\WirelessCable` 导入已有的设备与证书，所以换版本不会掉配对。

### 2.2 手机端

系统要求：Android 11 及以上。

1. 安装 `WirelessCable.apk`（覆盖安装不会掉配对）。
2. 首次打开会给几个权限，按下面处理：

| 权限             | 必须？      | 不给会怎样                        |
| -------------- | -------- | ---------------------------- |
| 通知             | 建议       | 服务照常运行；只是看不到状态通知，也没法从通知栏关后台同步 |
| 所有文件访问权        | 接收文件必须   | 收不到文件，界面提示「需要所有文件访问权」        |
| 电池 → 不限制（后台运行） | **强烈建议** | 息屏约一分钟后被系统冻结：传输停半路、通知还在但不再响应 |

> ColorOS / FuntouchOS 这类 ROM，真正的开关是「电池 → 后台耗电管理 → 允许后台运行」。  
> 设好之后实测息屏 40 秒传完 1 GB（约 27 MB/s）不掉。

## 3. 配对

只做一次，之后每次自动连。

### 方式一：手机扫电脑（最常用）

1. 电脑端 → 首页 → 「配对码」，屏幕上出现二维码。
2. 手机 → 首页 → 「扫码配对」→ 对准屏幕。

二维码里是**一次性随机数 + 局域网地址 + 端口 + 证书指纹**，不含长期密钥；扫完即失效。

### 方式二：手机发现电脑

1. 手机 → 首页 → 「扫描电脑」（同一局域网内自动发现，走 mDNS）。
2. 点列表里的电脑 → 电脑端会弹出配对确认，**在电脑上点确认**。

### 配对之后

- 手机首页「电脑」卡片里会列出已配对的电脑，当前那台标「已连接」。
- 设备名后面跟四位短 ID（如 `MY-PC · 3F7A`）——两台电脑同名时靠它区分，配对记录里也是这个全名。
- 电脑端「设备管理」里能看到这台手机、它的授权目录和权限档位。
- 电脑端每个设备行有「管理」：改权限、看历史、断开、移除。**移除设备只删记录，不删文件。**

## 5. 传文件

### 5.1 手机 → 电脑

两种入口，结果一样：

- 手机「文件」页选中文件 → 发送到电脑；
- 电脑「手机文件」页选中 → 保存到电脑（其实是给手机下发一个下载作业，由手机执行）。

落点：

- 默认进**电脑的接收目录**，并按设备名分子文件夹（`接收目录\<设备名>\`）。
- 接收目录可在「设置 → 接收目录」改；**只影响之后接收的文件**，已经在传的不受影响。

### 5.2 电脑 → 手机

先在「共享目录」里把电脑上的目录授权给手机，手机「文件」页就能看到并下载。

- 手机下载后落到 `Download/WirelessCable`（系统「下载」目录下的固定子目录）。
- 电脑端也能反过来「发送到手机」：手机在线时会立刻执行，离线则排队，**下次连上自动补做**。
- 单个文件直接传；整个文件夹会展开成多个任务，在手机上按原目录结构建目录。

### 5.3 从别的应用直接分享（相册、文件管理器、浏览器）

任何应用里点「分享」→ 选 **WirelessCable** → 弹「发送到」：

| 选项    | 结果                             |
| ----- | ------------------------------ |
| 列出的电脑 | 标「已连接」的直接发；标「未连接」的会先把它找回来、连上再发 |
| 当面直连  | 不经过电脑：直接进入出码页，对方扫码就能拉这批文件      |
| 取消    | 随时可点，连电脑的过程也会一起停               |

规则：

- 落点永远是电脑的**默认接收目录**（分享没有"当前目录"）。重名会自动加 ` (1)`、` (2)`。
- 纯文字（浏览器、微信里的链接）会先落成一个 `分享文本-<时间戳>.txt` 再传——  
  英文界面下文件名是 `Shared text-<时间戳>.txt`。传输协议只认文件，没有"发一段话"。
- 点「未连接」的电脑会立刻尝试连上，连不上会直接告诉你，不会一直转圈。
- 传输中再分享一次，会提示「已有传输在进行，请稍候」。

### 5.4 权限档位

每个授权目录单独设：

| 档位      | 手机能做什么             |
| ------- | ------------------ |
| 无权限     | 看不到                |
| 只读      | 只能浏览、下载            |
| 读写（不能删） | 上传、新建、改名、移动；删除按钮灰显 |
| 读写 + 删除 | 全部                 |

「整机访问」是另一套四档（在设备行的「授权」弹窗里）：

| 档 | 含义                |
| - | ----------------- |
| 0 | 关闭                |
| 1 | 只读（能看所有盘符，不能写）    |
| 2 | 读写，不含删除           |
| 3 | 读写 + 删除（新设备默认这一档） |

档位只管"允许到什么程度"，真正能看哪个盘还要手机端授权根目录。删除被拒时会明确提示  
「删除被拒」，不会静默失败。

### 5.5 传输页（手机）

- 两个页签：**进行中** / **已完成**（电脑端叫「传输中心」，按 全部 / 我发送的 / 我收到的 筛选）。
- 点行首圆圈进入多选，底部出现：`全选 / 打开 / 取消任务 / 删除 / 完成`。  
  「全选」选的是**当前页签、当前筛选下看得见的行**；全选中后按钮变「取消全选」。
- **暂停**是逐块生效的（每一块之前都会检查），不是"下一块才开始"。
- 删传输记录的安全边界：只有**上传方向**、且路径在共享目录里的文件才会被一起删；  
  下载方向的本地路径是你自己的原文件，永远不删。

## 6. 断线与重连

- 手机每 **10 秒**发一次心跳；**30 秒**没有心跳，电脑端判为离线（最坏约 40 秒翻状态）。
- 设备行状态优先级：已撤销 > 已断开 > 已连接 > 断开。
- **断开是会话级的**：断开会话不影响配对、令牌和授权。电脑端点「连接」清除标记，  
  手机通常 30 秒内自己接上。
- 手机上的「后台同步」关掉后，退到后台就不再响应电脑（但前台仍可用）。

## 7. 电脑热点（手机没 Wi-Fi 时）

热点**不用手动开关**——生成配对码时会自动尝试开启：

1. 电脑端 → 首页 → 生成配对码。
2. 首页会显示「备用热点 <名称> · 密码 <口令>」（密码由程序自己配，系统接口读不回来，所以写在这儿）。
3. 手机先试二维码里的局域网地址，**全都不通时才自动连**这个热点。

> 热点地址（通常是 `192.168.137.x`）**不会**写进二维码。旧版界面首页有「关闭热点」按钮。

---

## 8. 当面直连（两台手机之间）

不经过电脑，两台手机面对面传：

1. 一台「当面直连」→ 出码；另一台 → 扫码。
2. 出一台起一次性 HTTPS 服务，证书自签、扫码方校验指纹。
3. 能传文件，也能互推应用（APK）：出码方把应用加进共享清单，扫码方直接下载安装。

**会话是一次性的**：断开、退出、换网络都要重新扫码。

## 9. 通知与角标

| 位置            | 表现                                            |
| ------------- | --------------------------------------------- |
| 安卓常驻通知        | 只有一条（前台服务，Android 强制要求），已压到最低：不响、不亮屏、无时间戳     |
| 安卓事件          | 收到文件 / 缺「所有文件访问权」/ 连接断开 → 弹一次，**5 秒自动消失**，不堆叠 |
| Windows 托盘    | 只有图形、透明底的图标（不是深蓝方块）                           |
| Windows 任务栏角标 | **有任务在传时**，任务栏按钮右下角出现角标，传完自动消失                |

安卓那条常驻通知删不掉；不想看到就在手机设置里关掉「后台同步」——代价是退到后台就收不到电脑的指令。

## 10. 常见问题

**手机连不上电脑**

1. 两台是不是连在同一个路由器上。**有线 + Wi-Fi、2.4G + 5G 都算同一个广播域**，  
   只要 mDNS 组播能过去就行——代码里没有任何 SSID / 频段 / 网段判断（见 10.1）。
2. 电脑端防火墙有没有放行（首次启动那个提示点了「取消」就要手动加）。
3. 电脑是不是换了网络/重启过：地址变了，重扫一次配对码即可。
4. 这两种会真的隔开设备：路由器的**访客网络**（单独 VLAN）和**AP 隔离 / 无线隔离**。  
   公司、酒店 Wi-Fi 常开这两项——用电脑热点绕过，或者扫码（二维码里带地址，不依赖组播）。

### 10.1 为什么"不用连同一个 Wi-Fi"

发现走的是 mDNS（DNS-SD），不是 Wi-Fi 关联信息：

- 电脑端 `MdnsAdvertiser` 发布 `_wirelesscable._tcp`，A 记录 + TXT 的 `addrs` 给出**所有物理网卡**的  
  IPv4（虚拟网卡按名字黑名单排除）；服务端 `ListenAnyIP` 监听全部网卡。
- 手机端用 Android NSD 收广播，只按 `deviceId` 去重，**不看 SSID、不看频段、不看网段**。  
  拿到候选后 `LocalSubnet.preferLocal` 只把"和手机同子网"的排前面，不丢弃其它地址，  
  随后逐个探测取第一个可达的。
- mDNS 是链路本地组播（224.0.0.251:5353）。家用路由器把有线口和两个频段桥在同一个广播域，  
  组播能过去，所以"一根网线 + 一个 Wi-Fi""2.4G 连手机、5G 连电脑"都能发现。
- 真正挡住的是**广播域被切开**：访客网络、AP 隔离、部分企业无线（组播抑制）。  
  这时扫码仍可用——二维码里带的是地址列表，不需要组播。

**「列表为空」有两种含义**

- 目录里确实没东西；
- 目录太深，超出了索引快照的范围（整机 2 万条 / 手选 5000 条，深度 4/8）。  
  在目录里新建了东西却看不到，页面上「刷新」一次就会现场重新列。

**传到一半停了，解锁后又自己继续**

手机被系统冻结了（见 2.2 的电池白名单）。传输是断点续传的，不会从头再来。

**手机上点删除没反应 / 报「删除被拒」**

该目录的权限档位是「读写（不能删）」，或者整机访问只到第 2 档。去电脑端把档位调到「读写 + 删除」。

**分享菜单里找不到 WirelessCable**

只在**分享面板**里，不在「打开方式」里——选文件时点「打开」是看不到的。  
另外刚装完新版本，系统的分享列表可能还是旧的，重启一次分享面板（或下拉刷新）就有了。

**换版本后要重新配对？**

不会。便携目录里的 `Data\` 和 `certs\` 就是配对信息，**别删**。真删了只能重新扫一次码。

## 11. 数据、日志与卸载

| 内容            | 位置（便携版）                 | 位置（单文件版）                                 |
| ------------- | ----------------------- | ---------------------------------------- |
| 数据库（设备/任务/授权） | `Data\wirelesscable.db` | `%LOCALAPPDATA%\WirelessCable\data\`     |
| 证书与密钥         | `Data\certs\`           | `%LOCALAPPDATA%\WirelessCable\certs\`    |
| 接收到的文件        | `Data\received\`        | `%LOCALAPPDATA%\WirelessCable\received\` |
| 日志            | `Logs\`                 | `%LOCALAPPDATA%\WirelessCable\logs\`     |
| 传输临时文件        | `TransferTemp\`         | `%LOCALAPPDATA%\WirelessCable\temp\`     |

- **卸载 = 删掉程序目录**（单文件版再删 `%LOCALAPPDATA%\WirelessCable`）。  
  删掉 `Data`/`certs` 就等于解除全部配对。
- 手机端卸载后配对信息一并消失，需要重新扫码。
- 出问题先看 `Logs\wirelesscable-<日期>.log`，日志里有每一步的请求与服务端判定。

## 12. 这一版还没做

- iOS 端（不排期）。
- 跨网段 / 走公网（设计上只走局域网）。
- 电脑主动连手机（手机不监听端口）。
- 手机间的多设备群发（当面直连是一次性一对一）。
