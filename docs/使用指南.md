# WirelessCable 使用指南

把手机和电脑连在一起：传文件、看手机里的东西、把照片视频发到电脑上。  
不用数据线，也不用上传到网盘。

**需要**：一台 Windows 10/11 电脑，一台安卓手机，两个连在**同一个路由器**下。

不用管它们是怎么连的——电脑插网线、手机用 Wi-Fi，或者一个在 2.4G、一个在 5G，都能互相找到。

---

## 一、装好

**电脑**：把 `WirelessCable.exe` 放到一个文件夹里，双击打开。  
第一次打开会弹「放行本机端口」→ 点「继续」，随后 Windows 要一次管理员权限，同意即可——它会自己加好防火墙规则，不用你手动设。

**手机**：安装 `WirelessCable.apk`，打开后按提示授权：

- **通知**：不给也能后台运行，只是看不到那条状态通知；
- **所有文件访问权**：不给的话，收到的文件放不进「下载」文件夹。

再顺手做一件事：在手机设置里找到本应用 → 电池 → 选「不限制后台运行」。  
不做也能用，但锁屏一会儿再传大文件，可能会停住。

---

## 二、配对（只做一次）

1. 电脑上点左侧「首页」，屏幕中间会出现一个**二维码**。
2. 手机上点「扫码配对」，对准电脑屏幕。
3. 电脑上出现"已连接"，就好了。

以后只要两台都在同一个 Wi-Fi，打开就自动连上，不用再扫。

> 手机找不到电脑？在手机首页点「扫描电脑」，从列表里点你那台电脑的名字，  
> 然后在电脑上点「允许」。

---

## 三、传文件

### 手机 → 电脑

两种做法，效果一样：

- **在手机上**：「文件」→ 选中文件 → 发送；
- **在电脑上**：「手机文件」→ 找到文件 → 保存到电脑。

文件会进电脑的**接收目录**（默认在程序数据里，可以在「设置 → 接收目录」改成桌面之类的常用位置）。  
同名文件不会覆盖，会自动变成 `照片 (1).jpg`。

### 电脑 → 手机

1. 电脑上点「共享目录」→ 添加一个文件夹（比如「下载」或「照片」）；
2. 手机上「文件」里就能看到它，点文件即可下载。

文件会存到手机的 **下载 / WirelessCable** 文件夹里。

### 从别的应用直接分享（最快）

在相册、文件管理器、浏览器里点「分享」→ 选 **WirelessCable**，会弹出一个选择框：

- 点你的电脑 → 直接发过去；
- 点「当面直连」→ 进入二维码页面，另一台手机扫码就能收（两台手机之间传，不经过电脑）；
- 点「取消」→ 不发了。

分享网页链接也行，会存成一个文本文件发过去。

---

## 四、在电脑上看手机

电脑上点「手机文件」，可以浏览手机里授权给电脑的文件夹，双击就能保存到电脑。

第一次用时要在手机上授权：手机「文件」→ 选择要给电脑看的文件夹。  
嫌麻烦可以打开「整机访问」，那样电脑能看到手机里所有文件。

**权限可以随时改**，每个文件夹单独设：

| 权限      | 手机/电脑能做什么     |
| ------- | ------------- |
| 无权限     | 看不到           |
| 只读      | 只能看、只能下载      |
| 读写（不能删） | 能上传、改名、移动，不能删 |
| 读写 + 删除 | 全部都可以         |

---

## 五、传输页

电脑的「传输中心」和手机的「传输」都能看到进度。

- 想停一下：点「暂停」，恢复网络或点继续都会接着传，不会从头再来；
- 不想要了：点「取消」；
- 传完的记录可以删掉（只是删记录，不会删已经传好的文件）。

---

## 六、几个常用设置

| 想做的事          | 在哪                             |
| ------------- | ------------------------------ |
| 改电脑接收文件的位置    | 电脑「设置 → 接收目录」                  |
| 手机没 Wi-Fi 也能传 | 电脑首页生成配对码时会自动开备用热点，名称与密码就在首页 |
| 换深色/浅色        | 电脑「设置 → 外观」                    |
| 关闭程序后仍在托盘运行   | 电脑托盘图标右键 → 旧版界面 → 设置里打开「关闭到托盘」 |

## 七、常见问题

**手机上显示"连不上电脑"**

1. 两台是不是连在同一个路由器上？**有线 + Wi-Fi、2.4G + 5G 都算同一个**，  
   只有这两种会隔开设备：路由器的「访客网络」，和设置里的「AP 隔离 / 无线隔离」。
2. 电脑防火墙是不是拦了？第一次那个提示要选「允许」。
3. 电脑换过网络或重启过？在手机首页点「重连」，还不行就重新扫一次二维码。

**电脑上看不到手机的文件**

多半是手机上还没授权那个文件夹。手机「文件」→ 授权；已经授权过就在电脑上点一下刷新。

**传到一半停了，解锁后又自己继续**

手机被系统"冻结"了。按第一条把后台运行设成「不限制」。

**文件存到哪了？**

- 手机收到：`下载 / WirelessCable`
- 电脑收到：你设置的接收目录（设置里能看到完整路径，也有「打开」按钮）

**分享菜单里找不到 WirelessCable**

它只出现在「分享」里，不在「打开方式」里。刚装完如果还没有，把分享面板关掉再打开一次。

**换了新版本要重新配对吗？**

不用。只要不删程序旁边的数据文件夹，配对一直有效。
